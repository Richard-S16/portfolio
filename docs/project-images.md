The four formerly masked assets use an eight-character content hash in their filenames to bypass cached masked copies. When replacing one, update its hash and data path as well; replacing bytes under the same URL can leave older optimized/browser copies visible.

Featured cards contain the complete screenshot without distortion; public case studies use intrinsic aspect ratios. Lenovo screenshots fill 16:9 panels above their summaries, in two desktop columns and one mobile column; they remain summaries only. Both dictionaries describe the actual images; screenshot interface text itself remains in the captured language.

For replacements, obtain public-use approval for the displayed content, inspect at readable resolution, verify metadata is stripped, then update dimensions and both localized alt texts. Browser tests check all nine homepage images, all eight localized case-study images, successful loading, full-width Lenovo panels and case-study aspect ratios. Responsive and accessibility checks remain in the same suite. Lighthouse has not been remeasured after image integration.
